tgen::miniblog(2): Fisher-Yates' algorithm

2026-06-21 · Originally published on Codeforces

This is a blog 2 of a series of blogs about algorithmic challenges I came across when creating tgen.

In this blog we will tackle:

  1. Generate a uniformly random permutation of length nnn;
  2. Generate kkk uniformly random distinct integers in the range [0,n)[0, n)[0,n) in O(klog⁡k)\mathcal O(k \log k)O(klogk) time.

In my previous blog tgen::miniblog(1) we saw a way to solve (2) in O(klog⁡2k)\mathcal O(k \log^2 k)O(klog2k) time, so we will improve this bound.

The Fisher-Yates’ algorithm is very simple. We start with the identity permutation p=[0,1,…,n−1]p = [0, 1, \dots, n-1]p=[0,1,…,n−1] and at the end we will have a permutation of ppp uniformly at random, that is, each permutation will be generated with probability 1n!\frac{1}{n!}n!1​. We will do the following.

std::vector<int> p(n);
for (int i = 0; i < n; i++) p[i] = i;
for (int i = 0; i < n; i++) {
    std::swap(p[i], p[next(i, n-1)]);
}
return p;

Algorithm 1: Fisher-Yates’ algorithm.

Here, next(left, right) is a function that returns a uniformly random integer in the range [left,right][\text{left}, \text{right}][left,right]. Let’s prove that the resulting permutation is uniform.

Theorem 1: Algorithm 1 creates a uniformly random permutation of length nnn.

Proof: Fix an arbitrary permutation π\piπ of 0,1,…,n−1{0, 1, \dots, n-1}0,1,…,n−1. We will compute the probability that Algorithm 1 outputs exactly π\piπ.

Observe that after iteration iii, the value stored at position iii will never move again, since all future swaps only involve positions greater than or equal to i+1i+1i+1.

Therefore, for the final permutation to be equal to π\piπ at iteration iii, the algorithm must place πi\pi_iπi​ at position iii.

Suppose that iterations 0,1,…,i−10, 1, \dots, i-10,1,…,i−1 have already placed the correct values. At the beginning of iteration iii, the positions i,i+1,…,n−1i, i+1, \dots, n-1i,i+1,…,n−1 contain exactly the values πi,πi+1,…,πn−1\pi_i, \pi_{i+1}, \dots, \pi_{n-1}πi​,πi+1​,…,πn−1​ in some order. Hence, among the indices i,i+1,…,n−1i, i+1, \dots, n-1i,i+1,…,n−1, there is exactly one index whose value is πi\pi_iπi​.

The algorithm chooses an index jjj uniformly at random from the range [i,n−1][i, n-1][i,n−1]. Since there are n−in-in−i possible choices for jjj, exactly one of which places πi\pi_iπi​ at position iii, conditioned on all previous iterations placing the correct values, the probability that iteration iii places the correct value is 1n−i\frac{1}{n-i}n−i1​.

Therefore, by multiplying these conditional probabilities, the probability that every iteration places the correct value is

∏i=0n−11n−i=1n!.\prod\limits_{i=0}^{n-1} \frac{1}{n-i} = \frac{1}{n!}.i=0∏n−1​n−i1​=n!1​.

Thus, the probability that Algorithm 1 outputs the permutation π\piπ is 1n!\frac{1}{n!}n!1​. Since this holds for every permutation π\piπ, the output distribution is uniform.

□\square□

Note that this can shuffle any list, not just the identity permutation.

To solve problem (2) using this idea, we would like to create an identity array of length nnn, shuffle it uniformly at random and then return the first kkk elements of that permutation. Since after shuffling every permutation is equally likely, then every distinct prefix of length kkk is also equally likely, with probability (n−k)!⋅1n!=(n−k)!n!(n-k)! \cdot \frac{1}{n!} = \frac{(n-k)!}{n!}(n−k)!⋅n!1​=n!(n−k)!​.

We can also check that each set of kkk numbers is represented exactly k!k!k! times, so each subset of size kkk of [0,n)[0, n)[0,n) is chosen with probability

k!⋅(n−k)!n!=1(nk),k! \cdot \frac{(n-k)!}{n!} = \frac{1}{\binom{n}{k}},k!⋅n!(n−k)!​=(kn​)1​,

so we can just sort the chosen list to get a uniformly random subset of kkk numbers in [0,n)[0, n)[0,n).

However, the problem is that nnn might be large, so we cannot explicitly create the permutation. But we only need to run the algorithm for kkk iterations, since other iterations won’t affect the first kkk elements of the shuffled permutation. So we can just run kkk iterations and use a map as the permutation (and if some element is not present, we initialize it with p[i]=ip[i] = ip[i]=i; some sort of lazy initialization).

std::map<int, int> p;
std::vector<int> ret(k);
for (int i = 0; i < k; i++) {
    int j = next(i, n-1);
    int p_i = p.count(i) ? p[i] : i;
    int p_j = p.count(j) ? p[j] : j;
    p[i] = p_j;
    p[j] = p_i;

    ret[i] = p[i];
}
return ret;

Algorithm 2: random kkk values in [0,n)[0, n)[0,n) by Fisher-Yates.

Algorithm 2 clearly runs in O(klog⁡k)\mathcal O(k \log k)O(klogk) time, and its output is uniformly random.
