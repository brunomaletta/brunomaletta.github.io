Baralho Alho

2025Original problem set

Statement

Researcher Isadora loves playing cards with her friends. More specifically, she plays a version called Baralho Alho, in which there are NNN cards (duplicates are allowed). Initially, the NNN cards are in a specific order: the iii-th card has value AiA_iAi​. Two cards are considered equal if they have the same value.

Before the game starts, Isadora declares: “I always shuffle Baralho Alho.” Naively, her friends agree and let her command the shuffling. Little do they know that Researcher Isadora loves to cheat. Her goal is to shuffle in such a way that, at the end, the iii-th card has value BiB_iBi​.

However, she knows only one kind of shuffle: it maps the card originally at position iii to position PiP_iPi​. For example, if P=[3,2,4,1]P=[3,2,4,1]P=[3,2,4,1], the first card goes to the third position, the second remains in place, the third goes to the fourth, and the fourth goes to the first. Thus, if the initial deck is [4,2,6,1][4,2,6,1][4,2,6,1], applying the shuffle produces [1,2,4,6][1,2,4,6][1,2,4,6].

Even with this limitation, Isadora is quite intelligent and plans to repeat the shuffle several times to reach new deck configurations.

Given AiA_iAi​, BiB_iBi​, and PiP_iPi​, determine the minimum number of times Isadora must apply the shuffle so that the deck reaches the desired order. If this is impossible, print IMPOSSIVEL. If the minimum number of shuffles is greater than 10910^9109, print DEMAIS.

Print the minimum number kkk of shuffles needed. If it is impossible, print IMPOSSIVEL. If the minimum kkk is greater than 10910^9109, print DEMAIS.

Tutorial

Required topics: permutations, string matching, and the Chinese remainder theorem.

Turning cycles into congruences

Decompose the permutation into cycles and handle each cycle independently. Applying the shuffle once rotates the values along every cycle by one position. Therefore, for each cycle, we need to find which rotations of its initial value sequence equal its target sequence.

Duplicate the initial sequence and search for the target sequence inside it with KMP, the Z-function, or another linear string-matching algorithm. If no rotation matches for any cycle, the answer is IMPOSSIVEL.

If a cycle admits shift aia_iai​ and its value sequence has minimal period mim_imi​, all its valid shifts are exactly

k≡ai(modmi).k\equiv a_i\pmod{m_i}.k≡ai​(modmi​).

We now have a system of congruences, one from each cycle, and need to combine them using the generalized Chinese remainder theorem. The complication is that their least common multiple can become enormous and overflow ordinary integer types. We should first decide whether the complete system is consistent, and only then merge congruences until the modulus becomes large enough.

Checking whether a solution exists

There are two useful approaches.

Approach 1: pairwise compatibility

After merging congruences with the same modulus, there are only O(N)O(\sqrt N)O(N​) distinct moduli. This follows because the moduli do not exceed their corresponding cycle lengths, and the sum of all distinct cycle lengths is at most NNN.

Two congruences

k≡ai(modmi),k≡aj(modmj)k\equiv a_i\pmod{m_i},\qquad k\equiv a_j\pmod{m_j}k≡ai​(modmi​),k≡aj​(modmj​)

are compatible if and only if

ai≡aj(modgcd⁡(mi,mj)).a_i\equiv a_j\pmod{\gcd(m_i,m_j)}.ai​≡aj​(modgcd(mi​,mj​)).

A system of congruences is solvable if and only if every pair is compatible. Thus, after deduplication, checking every pair takes O(N)O(N)O(N) time in total. See the pairwise solvability criterion for a proof.

Approach 2: split into prime powers

Factor each modulus into distinct prime-power factors:

mi=pi,1ei,1pi,2ei,2⋯pi,xiei,xi.m_i=p_{i,1}^{e_{i,1}}p_{i,2}^{e_{i,2}}\cdots p_{i,x_i}^{e_{i,x_i}}.mi​=pi,1ei,1​​pi,2ei,2​​⋯pi,xi​ei,xi​​​.

Because these factors are pairwise coprime, the congruence

k≡ai(modmi)k\equiv a_i\pmod{m_i}k≡ai​(modmi​)

is equivalent to the system

k≡ai(modpi,1ei,1),…,k≡ai(modpi,xiei,xi).k\equiv a_i\pmod{p_{i,1}^{e_{i,1}}},\quad\ldots,\quad k\equiv a_i\pmod{p_{i,x_i}^{e_{i,x_i}}}.k≡ai​(modpi,1ei,1​​),…,k≡ai​(modpi,xi​ei,xi​​​).

Do this for every original congruence, then group the resulting conditions by prime. For one fixed prime ppp, we obtain conditions of the form

k≡b0(modpe0),k≡b1(modpe1),…k\equiv b_0\pmod{p^{e_0}},\quad k\equiv b_1\pmod{p^{e_1}},\quad\ldotsk≡b0​(modpe0​),k≡b1​(modpe1​),…

First, equal powers must have equal residues. Conditions at different powers must also agree after reduction to the smaller power: for example, k≡7(mod25)k\equiv7\pmod{25}k≡7(mod25) implies k≡2(mod5)k\equiv2\pmod5k≡2(mod5), so it is incompatible with k≡1(mod5)k\equiv1\pmod5k≡1(mod5).

If every prime group is internally consistent, keep only its condition with the largest exponent. The remaining moduli are pairwise coprime, so the Chinese remainder theorem guarantees that the complete system has a solution.

Avoiding overflow and deciding DEMAIS

Once consistency is known, merge congruences one at a time with generalized CRT. Maintain the smallest nonnegative solution xxx and the combined modulus LLL. All solutions processed so far are

x,x+L,x+2L,…x, x+L, x+2L,\ldotsx,x+L,x+2L,…

Stop as soon as L>109L>10^9L>109. Test xxx against all original congruences:

  • if it satisfies all of them and x≤109x\le10^9x≤109, print xxx;
  • otherwise, every other solution is at least x+L>109x+L>10^9x+L>109, so print DEMAIS.

The earlier consistency check is essential: without it, stopping early could incorrectly print DEMAIS for a system that is actually impossible.

Cycle decomposition and string matching take O(N)O(N)O(N). With the pairwise compatibility approach, feasibility also takes O(N)O(N)O(N) after deduplication; factoring for the prime-power approach can likewise be supported by a smallest-prime-factor sieve. The final capped CRT merge is linear in the number of distinct congruences.
