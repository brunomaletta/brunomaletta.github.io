ICPC Latin America Subregionals · Problem G

Genes

2026

Statement

A DNA sequence is represented by a string TTT. Several genes are also known, represented by strings and ordered from most relevant to least relevant. The genes are numbered sequentially, starting from 1.

QQQ queries are made. Each delimits a segment of TTT between indices LiL_iLi​ and RiR_iRi​, inclusive. For each query, determine the index of the most relevant gene that occurs entirely as a substring of that segment.

Input

The first line contains TTT (1≤∣T∣≤1051\le|T|\le10^51≤∣T∣≤105). The second line contains the number GGG of genes (1≤G≤5⋅1051\le G\le5\cdot10^51≤G≤5⋅105). Each of the following GGG lines contains one gene, from most to least relevant. Every gene is nonempty. The genes are distinct, and the sum SSS of their lengths is at most 5⋅1055\cdot10^55⋅105.

The next line contains QQQ (1≤Q≤1051\le Q\le10^51≤Q≤105). Each of the following QQQ lines contains Li,RiL_i,R_iLi​,Ri​ (1≤Li≤Ri≤∣T∣1\le L_i\le R_i\le|T|1≤Li​≤Ri​≤∣T∣), the inclusive query bounds.

All strings contain only the letters A, C, G, and T.

Output

For each query, print the index of the most relevant gene that occurs entirely within the corresponding segment. If none occurs, print −1-1−1.

Tutorial

We use Aho–Corasick to enumerate every occurrence of every gene in TTT.

Bounding the number of matches

Lemma. The total number of gene occurrences in TTT is O(∣T∣S)O(|T|\sqrt S)O(∣T∣S​), where SSS is the sum of the gene lengths.

Consider all genes whose occurrences end at one fixed position of TTT. Since the genes are distinct, two of them cannot have the same length: the substring with a given length and ending position is unique. If there are kkk such genes, their lengths are at least 1,2,…,k1,2,\ldots,k1,2,…,k. Therefore

1+2+⋯+k≤S.1+2+\cdots+k \le S.1+2+⋯+k≤S.

Since this sum is Θ(k2)\Theta(k^2)Θ(k2), we have k=O(S)k=O(\sqrt S)k=O(S​). Applying this bound at every text position proves the lemma.

Processing queries offline

Group each query [l,r][l,r][l,r] by its right endpoint rrr, then scan TTT from left to right with the Aho–Corasick automaton.

Suppose position rrr has just been processed. For every gene occurrence ending there, let ppp be its starting position and ggg its gene index. At position ppp, store the minimum index of any occurrence seen so far that starts there.

All stored occurrences already end at or before rrr. Consequently, the answer to query [l,r][l,r][l,r] is simply the minimum stored gene index over starting positions p≥lp\ge lp≥l. This condition guarantees that the entire occurrence is inside the query interval.

We need a data structure supporting:

  1. update(p, g): replace the value at position ppp with its minimum with ggg;
  2. suffix_min(l): find the minimum value at positions l,l+1,…,∣T∣l,l+1,\ldots,|T|l,l+1,…,∣T∣.

Square-root decomposition

Split the starting positions into blocks of size B≈∣T∣B\approx\sqrt{|T|}B≈∣T∣​. Store both the individual value at every position and the minimum value of each block.

An update only decreases one individual value and its block minimum, so it takes O(1)O(1)O(1). For a suffix query, inspect individual positions until reaching a block boundary, use the precomputed minimum for every complete block, and inspect the final partial block. This takes

O(∣T∣+∣T∣∣T∣)=O(∣T∣).O\left(\sqrt{|T|}+\frac{|T|}{\sqrt{|T|}}\right)=O(\sqrt{|T|}).O(∣T∣​+∣T∣​∣T∣​)=O(∣T∣​).

Aho–Corasick construction costs O(S)O(S)O(S). Match enumeration performs O(∣T∣S)O(|T|\sqrt S)O(∣T∣S​) constant-time updates, and the QQQ queries cost O(Q∣T∣)O(Q\sqrt{|T|})O(Q∣T∣​). The final complexity is

O(S+∣T∣S+Q∣T∣)O\left(S+|T|\sqrt S+Q\sqrt{|T|}\right)O(S+∣T∣S​+Q∣T∣​)

time and O(S+∣T∣+Q)O(S+|T|+Q)O(S+∣T∣+Q) memory.
