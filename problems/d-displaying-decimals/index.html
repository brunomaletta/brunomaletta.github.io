ICPC Latin America Championship · Problem D

Displaying Decimals

2025By Bruno MonteiroOriginal problem set

Statement

After the BRICS group introduced the International Common Payment Currency (ICPC), all currencies (like real, peso, dollar, etc.) are now defined by their values in ICPCs.

To help people navigate this new world order, you decided to create a website to compute conversion rates between currencies. The website handles NNN currencies, numbered from 1 to NNN. Each currency iii has an associated integer value AiA_iAi​, indicating that one unit of currency iii is worth AiA_iAi​ ICPCs.

The user selects a source currency iii and then a target currency jjj (possibly j=ij=ij=i), and the website displays the conversion rate between them: the exact decimal representation of Ai/AjA_i/A_jAi​/Aj​.

To deal with repeating decimals, you display only the first period, represented by a line above it when one exists. Thus 4/4=14/4=14/4=1 requires 1 digit, 4/3=1.3‾4/3=1.\overline34/3=1.3 requires 2 digits, 41/4=10.2541/4=10.2541/4=10.25 requires 4 digits, and 3/14=0.2142857‾3/14=0.2\overline{142857}3/14=0.2142857 requires 8 digits.

Your website has been running successfully for quite some time. As part of your performance analytics, you want to compute the expected display size of conversion-rate pages.

Given A1,A2,…,ANA_1,A_2,\ldots,A_NA1​,A2​,…,AN​, compute the expected number of digits needed to display Ai/AjA_i/A_jAi​/Aj​ when iii and jjj are chosen independently and uniformly at random from 111 through NNN.

Input

The first line contains NNN (1≤N≤1051\le N\le10^51≤N≤105), the number of currencies. The second contains A1,A2,…,ANA_1,A_2,\ldots,A_NA1​,A2​,…,AN​ (1≤Ai≤1051\le A_i\le10^51≤Ai​≤105), where AiA_iAi​ is the value of one unit of currency iii in ICPCs.

Computing the fractional length

The integer part contains at most ⌊log⁡10M⌋+1≤6\lfloor\log_{10}M\rfloor+1\le6⌊log10​M⌋+1≤6 digits. Handle each possible digit count ddd separately.

For a fixed normalized denominator yyy, the numerator has d≥2d\ge2d≥2 integer digits precisely when

y⋅10d−1≤x<y⋅10d.y\cdot10^{d-1}\le x<y\cdot10^d.y⋅10d−1≤x<y⋅10d.
